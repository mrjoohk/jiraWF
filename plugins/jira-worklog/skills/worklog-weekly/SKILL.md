# 주간 롤업

일일 기록 → 주간 업무일지. **읽기 전용이다.**

## 절대 규칙

1. **주간 파일은 파생물이다.** 언제든 지우고 다시 만들 수 있어야 하며, 같은 daily 입력에서는 같은 결과가 나와야 한다.
2. **daily 파일에 없는 내용을 쓰지 않는다.** 기억이나 대화 맥락에서 보충하지 않는다.
3. 문장화는 `worklog-writer` 서브에이전트가 한다.

## 절차

0. 대상 폴더(`WF_HOME`)를 확정한다. 폴더마다 맡은 범위가 다르므로 주간일지도 폴더별로 따로 만든다.
1. 대상 주(월~금)의 `daily/*.md`를 수집한다. 빠진 날이 있으면 **그 사실을 일지에 명시**한다(휴가·미실행 구분은 사람 몫이다).
2. 각 파일에서 "지난 실행 이후 변동" + "진행 메모"를 추출한다. "오늘 할 일"은 계획이지 실적이 아니므로 제외한다.
3. `worklog-writer` 서브에이전트를 생성해 **과제(Epic)별로 묶은** 주간 요약을 받는다. 구성:
   - 과제별 진행 사항
   - 완료된 항목 (상태가 Done으로 전이된 것)
   - 미해결·정체 항목과 그 사유
   - 다음 주로 넘어가는 것
4. `weekly/{YY}W{ww}.md`로 저장한다. 하단에 입력으로 쓴 daily 파일 목록을 남긴다 — 재생성 시 대조 기준이다.
5. 사용자에게는 과제별 한 줄 요약과 파일 경로만 보고한다.
